# Security Policy

## Supported Scope

This repository contains documentation and showcase material only.

## Reporting a Vulnerability

Please open a private report by creating an Issue with minimal reproduction details and clearly marking it as a security concern.

Include:
- affected component (frontend/backend/deployment)
- impact summary
- reproducibility details
- suggested mitigation if available

## Response Target

Initial triage target: within 5 business days.

## Safe Disclosure

Please do not publish vulnerability details publicly until remediation guidance is provided.
