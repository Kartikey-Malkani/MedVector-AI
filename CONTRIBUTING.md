# Contributing Guidelines

Thanks for your interest in MedVector AI.

This repository is documentation-only and intended for project showcase.

## What Contributions Are Welcome

- documentation improvements
- typo and clarity fixes
- architecture explanation improvements
- demo narrative suggestions

## What Is Not Accepted Here

- source code contributions
- reverse-engineering requests
- requests to publish private implementation details

## How To Contribute

1. Open an Issue with your suggestion.
2. Discuss scope with maintainer.
3. Submit a Pull Request for approved documentation changes.

## Standards

- keep changes concise and factual
- do not include sensitive, proprietary, or patient data
- keep language professional and clear
