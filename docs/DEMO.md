# Demo Guide

## What To Highlight

- retrieval-grounded answer generation
- source traceability and chunk details
- enterprise upload to indexing lifecycle
- latency split: CAG vs RAG

## Suggested Demo Flow

1. Ask a common medical question.
2. Open source cards and inspect cited chunk.
3. Show cache hit behavior on repeat query.
4. Upload an enterprise PDF.
5. Show indexing completion and new retrieval context.

## Audience Notes

- For recruiters: emphasize end-to-end system thinking.
- For engineers: emphasize architecture and failure handling.
- For product: emphasize explainability and UX clarity.
