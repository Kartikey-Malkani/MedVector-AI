# Feature Set

## End User Features

- medical query answering with cited evidence
- chunk-level source inspection
- clickable citations linked to source panel
- dark/light mode UX support
- upload and indexing experience for enterprise documents

## Explainability Features

- source cards with chunk identifiers
- selected-source detail panel
- full chunk preview for long evidence text

## Performance Features

- separate CAG and RAG latency reporting
- cache hit visibility
- retrieval optimization controls

## Platform Features

- cloud deployment support
- environment-based configuration
- API-driven frontend integration

## Governance & Safety Features

- restricted source repository model
- security reporting channel
- documentation-first public showcase
